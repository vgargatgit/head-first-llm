# Repository instructions

## Asset tracker

Every agent that completes chapter asset work must update the corresponding row
in `asset-tracker.md` as part of the same task:

- If the task was to review a chapter, set `Reviewed` to `☑` and `Generated` to
  `N/A`.
- If the task was to generate assets for a chapter, set `Generated` to `☑` and
  `Reviewed` to `N/A`.

Use exactly `☑` and `N/A` for these values. Do not leave the other status as
`☐`, and do not use alternate wording such as `Not Applicable`.
