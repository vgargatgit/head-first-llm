# Chapter 19 artwork

Eleven production illustrations for **The Decoder Borrows the Encoder’s
Notes**, generated with the built-in image-generation tool from
`docs/chapter-19/chapter-19-scene-plan.md`.

## Shared prompt lock

- 4:3 landscape textbook infographic on warm graph paper
- hand-inked outlines with colored-pencil and watercolor texture
- chunky uppercase lettering, rounded bordered panels, and friendly operator
  characters
- decoder objects in purple, encoder memory in blue, orange flow arrows, and
  mixed retrievals in purple-blue
- preserve source/target ownership, matrix orientation, exact chapter values,
  and six-decimal results
- avoid photorealism, glossy 3D, tiny prose, causal source masks, literal
  copying interpretations, and watermarks

## Scene prompts

1. Translator creates a decoder Query and consults a fixed encoder note wall.
2. Compare self-attention and cross-attention Q/K/V provenance.
3. Track `S`, `T`, `d_k`, `d_v`, and every cross-attention tensor shape.
4. Run the five-station compare, scale, source-mask, normalise, retrieve line.
5. Calculate the exact three Query–Key dot products from the manuscript.
6. Scale, source-mask, and softmax to the exact six-decimal weights.
7. Combine weighted Values into the canonical retrieved vector.
8. Generalise to four target rows by three source columns and one-way flow.
9. Contrast fixed source K/V with the growing target self-attention cache.
10. Show independent cross-attention heads and the three distinct mask jobs.
11. Correct seven misconceptions and hand the completed model to Chapter 20.
