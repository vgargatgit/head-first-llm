# Canonical Running-Example Ledger

**Status:** Canonical editorial source for the `THE CAT SAT` worked path  
**Scope:** Chapters 1–11  
**Verification:** `node scripts/verify-running-example.mjs`

## Authority

This ledger is the single source of truth for the numerical inference example. Chapter prose remains the teaching narrative, but every fixed value, learned parameter, derived tensor, shape, owning chapter, and source heading is recorded below. A change to a worked value must update this ledger and every chapter that carries the value forward.

## Precision policy

- Chapter display values are canonical. Most derived tensors use six decimals; exact teaching constants may use fewer.
- Verification uses full floating-point arithmetic and an absolute tolerance of `0.000002`.
- Later chapters may intentionally start from a displayed checkpoint. The verifier follows those editorial handoffs instead of inventing hidden precision.
- Do not repeatedly round inside one calculation. A one-unit difference in the sixth decimal is acceptable only within the documented tolerance.
- `-Infinity` is the causal-mask rule value, not a finite learned number.

## Path and ownership

```text
X -> Q1,K1 -> scores/mask/A1 -> V1/Z1
  -> independent Head 2 Q2/K2/V2/A2/Z2
  -> H -> W^O/Y -> residual R1 -> LayerNorm N
  -> MLP Pmlp/ReLU U/F -> residual R2 -> LayerNorm O=X^(1)
  -> toy Blocks 2 and 3 -> final normalised SAT state
  -> vocabulary logits -> probabilities
```

Chapter 9's `Epos + Ppos = X` is an architecture-specific additive illustration, not an extra step after Chapter 8 and not a requirement for RoPE. Chapter 10's Block 2 and Block 3 updates are explicitly illustrative because later blocks own different learned parameters.
